# Phase 5 data boundary

The 40 held-out statements form ten four-task families: heterogeneous composed witnesses, typed products, inverse-function consequences, noncommutative conjugation, lattice sandwich constraints, image/preimage roundtrips, pointwise set exclusion, quantified choice, intermediate relation witnesses, and heterogeneous binary congruence. Statements were written independently without importing solutions. No claim of new mathematics is made.

All statements elaborate in the unchanged Phase 1 mathematical import environment. Native reducible type trees and exact typed dependency-graph isomorphism (including binder renaming/permutation) compare them against every Phase 1–4 task, Phase 3/4 pilots, the six Phase 5 development pilots and earlier Phase 5 statements. The freeze records all 212 trees. No duplicate pairs were found. This audit cannot decide arbitrary logical equivalence.

Manual family review: composed witnesses use two heterogeneous functions, unlike the Phase 4 single transport witness; products introduce a new carrier; inverse-function obligations concern retracts rather than arbitrary relations; conjugation uses noncommutative nested cancellation rather than one terminal inverse; lattice tasks combine upper/lower obligations rather than projections alone; images and inverse-function recovery add existential membership absent from Phase 4 preimages; pointwise exclusion uses membership/negation contexts rather than subset partitions; quantified choice combines pointwise disjunction with existential/universal conclusions; intermediate witnesses expose relational composition rather than only transporting edges; binary congruence changes two heterogeneous arguments. Shared elementary conjunction, equality, rewriting and subset primitives remain. Families are not claimed to be independent mathematical theories. The family-cluster uncertainty analysis reflects this limited diversity.

Training is restricted to the frozen 48 original development IDs. Twelve order development IDs form the whole-family hyperparameter validation split. Source proofs are independently audited before replay. Up to three native source states per theorem are probed, at most 36 actual candidate applications per state, with at most three bounded continuations. Source positives outside the deployment cap are explicitly marked. Accepted but unexplored/censored alternatives never become negatives. The six pilots calibrate mechanics and difficulty but never train the model.

The protocol, index, final statements, candidate allocation, budgets, arm matrix, labels, hyperparameters and metrics are frozen before model selection. The original and Phase 4 generators, original verifier, previous evidence and previous trained models remain reference baselines. The model and runner source hashes receive an additional pre-evaluation freeze. No final-test outcome may change these artifacts.
