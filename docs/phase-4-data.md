# Phase 4 data and overlap boundaries

The 32 final statements in `benchmarks/phase4/evaluation.json` span eight families: contraposition obligations; quantified witnesses; function-preserved relations; lattice meet/join bounds; group inverse contexts; contextual cubic semiring identities; set preimages; set partitions. Six separate development-only pilots calibrate the 12-depth/80-expansion/600-attempt budget. All statements were designed without importing public benchmark solutions; all final tasks are retained.

The pre-selection freeze audits 166 elaborated statements: Phase 1–3 training/evaluation and Phase 3/4 pilots plus the new test set. Reducible native Lean expression normalization and exact typed graph isomorphism permit alpha renaming and independent binder permutation. No duplicates were found. This does **not** decide arbitrary semantic equivalence or remove shared elementary mathematical operations.

Manual relevant-overlap review: contraposition reuses implication/contradiction primitives, but introduces negative multi-obligation routes; quantified witnesses share existential introduction but require dependent predicate conjunction/transport; function-relational tasks share abstract relation/transitivity but add repeated function transport and fixed points; lattice bounds add meet/join structure absent in the previous route products; group tasks introduce inverse cancellation beyond monoid identity rewrites; cubic semiring identities reuse ring normalization but change algebraic assumptions, degree and factored products; preimages add cross-type function membership transport; partition tasks reuse set operations but change their elimination/product obligation graphs. Shared final subgoals are unavoidable in elementary mathematics. Results indicate limited family transfer on a hand-authored curriculum, not general mathematical reasoning or benchmark contamination immunity.

Training and validation only access the 48 original Phase 1 development IDs and the immutable Phase 3 development continuation records. Verified nonterminal successors give fixed-policy observed-cost targets; censored, invalid and unselected alternatives give no regression target. The validation split holds aside entire order development theorems. Prior Phase 3 held-out failure diagnostics are exploratory; they cannot train or select the model and are not new unseen-test evidence. Both exact earlier research hashes and final task/protocol hashes are recorded in the freeze.
